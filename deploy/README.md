# Деплой TChat на сервер + встраивание в Prizm

TChat в вебе состоит из двух частей:

- **Десктоп (Electron)** — полный контроль-центр с интеграциями чатов и DonationAlerts. Собирается в Windows-приложение.
- **Веб-сервер (`scripts/serve.js`)** — headless-режим без Electron. Отдаёт оверлеи, ассеты и мобильный пульт. Его размещаем на сервере: открывать с телефона в браузере и вставлять оверлеи в Prizm/OBS по ссылке.

> `.sh`-скрипты запускаются **на сервере** (там Linux). На вашем ПК ничего запускать через bash не нужно.

## Вариант A — деплой с Windows (без WSL/bash) ← рекомендуется

Нужен Windows 10 (1809+) или Windows 11 — в них уже встроены `ssh`, `scp`, `tar`.
Если вдруг `ssh` нет: Параметры → Приложения → Дополнительные компоненты → добавить «Клиент OpenSSH».

1. Открыть папку проекта `C:\TChat`.
2. Двойной клик по **`deploy\deploy-windows.bat`**.
3. Когда попросит — ввести пароль сервера. Могут спросить 1–2 раза, это нормально.

Скрипт сам упакует проект (без `node_modules`, `youtube-bypass` и кешей), зальёт на сервер, поставит Node.js, зависимости, systemd-сервис и nginx (порт 80 → 3000).

После — открыть в браузере:

- Лендинг + пульт: `http://195.62.49.244/tchat/`
- Статус: `http://195.62.49.244/tchat/health`

## Вариант B — деплой с Linux/macOS/WSL

```bash
TCHAT_DEPLOY_PASS='<пароль сервера>' bash deploy/deploy.sh
# либо, если настроены SSH-ключи:
bash deploy/deploy.sh
```

## Управление сервисом (на сервере)

```bash
systemctl status tchat
systemctl restart tchat
journalctl -u tchat -f
```

## Встраивание в Prizm (браузер-источник по ссылке)

Оверлеи с прозрачным фоном — вставляются в Prizm как источник «Браузер» по ссылке:

| Оверлей | Ссылка |
|---------|--------|
| Полный стрим-оверлей | `http://195.62.49.244/tchat/widgets/stream.html` |
| Алерты (донаты/подписки) | `http://195.62.49.244/tchat/widgets/alerts.html` |
| Чат | `http://195.62.49.244/tchat/widgets/chat.html` |
| Цель сбора | `http://195.62.49.244/tchat/widgets/goal.html` |
| Музыка | `http://195.62.49.244/tchat/widgets/music.html` |
| Таймер | `http://195.62.49.244/tchat/widgets/countdown.html` |
| Задачи | `http://195.62.49.244/tchat/widgets/tasks.html` |

В Prizm: добавить источник **Браузер** → вставить ссылку → задать размер (напр. 1920×1080 для stream.html). Фон останется прозрачным.

## Безопасность

- Пароль root лучше заменить на SSH-ключ и отключить парольный вход.
- Для публичного домена включите HTTPS (Let's Encrypt / certbot) — тогда работает и TWA-Android, и Prizm по https.
- Не коммитьте пароль в git.
