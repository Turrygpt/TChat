# Чибики

12 PNG с настоящим альфа-каналом: капитан, слесарь, волшебница, кладовщик,
лётчик, водитель, роковая женщина, военный, гном, доктор, строитель и бизнесмен.
Сгенерированы встроенным image_gen. Точные промпты сохранены в `prompts.json`
и `prompts-extra.json`.

Настройка: «Чибики» в левом меню. Выберите образы, название награды,
площадку, сторону и длительность. Включите появление за баллы и сохраните.
Один выбранный образ всегда используется, несколько выбираются случайно.
В «Профили» можно назначить зрителю конкретного чибика. Назначение действует
для всех связанных аккаунтов профиля и имеет приоритет над общим набором.
Выбор «Случайный» снимает назначение и возвращает общий случайный выбор.
Кнопка «Показать в OBS» сохраняет настройки и отправляет тест даже при выключенной автоматике.
В OBS используйте общий `http://localhost:3000/widgets/stream.html` (1920 × 1080).
Чибики встроены в него; дополнительный источник не нужен.
`?preview=1` включает демонстрацию с фоном, для OBS параметр нужно убрать.

Текущие PNG — цельные готовые костюмы. Каталог `src/chibis.js` и рендерер
поддерживают слои `body`, `outfit`, `hat` в этом порядке. Для будущего гардероба
нужны базовые персонажи без одежды и отдельные прозрачные слои, совмещённые
на одном квадратном холсте. Уже нарисованные шапки нельзя заменить наложением:
для сменного гардероба необходимо подготовить соответствующие исходники.
Загрузчик пользовательских образов и редактор гардероба в эту версию не входят.
Будущие загрузки должны сохраняться в userData/assets/chibis, не в папку приложения.

Настройки Electron сохраняются в userData/settings/chibis.json. На старте
автоматические появления выключены. Награды Twitch поступают через существующее
подключение наград; стандартное выделенное сообщение — через Twitch-чат.
VK использует существующий обработчик наград. Если сервис не передаёт текст,
отображается «Спасибо за стрим!». Повторные ID наград отбрасываются, до 30
сообщений ожидают последовательного показа; сверх этого новые события пропускаются.
Облегчённый сервер `createWidgetServer` предоставляет каталог и демонстрационный
endpoint, но не подключает площадки и не сохраняет настройки.

Проверки: `node scripts/chibis.test.js`, `npm.cmd run server:check`, `npm.cmd run smoke:test`.
