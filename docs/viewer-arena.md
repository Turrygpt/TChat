# Арена зрителей

В TChat откройте «Чибики», блок «Арена зрителей». Включите арену и сохраните.
Она появляется внизу существующего общего OBS-оверлея `/widgets/stream.html`.
Дополнительный источник OBS не нужен. По умолчанию арена выключена.

На плашке показаны только команды старта/возрождения:
`!бой бабка`, `!бой весло`, `!бой алкоголик`, `!бой офис`, `!бой слесарь`.
После смерти персонаж не возрождается сам: нужна новая команда через 30 секунд.
Повторная команда живого игрока не создаёт копию, не лечит и не меняет персонажа.
Старые команды `!бой`, `!fight`, `!перс` и `!выход` сохранены для совместимости,
но не рекламируются в экранной подсказке.

Бойцы сами сближаются и атакуют. Есть замах, удар, получение урона и смерть.
Удар даёт 3 опыта, победа — ещё 30. Уровень: `1 + floor(sqrt(XP / 30))`,
максимум 30. Облик меняется на уровнях 5 и 10. Статы применяются сразу при получении уровня:
- максимальное HP: `100 + 8 × (уровень − 1)`;
- сила: `12 × (1 + 0.035 × (уровень − 1))`;
- базовый интервал атаки: `1000 / (1 + 0.025 × (уровень − 1))` мс.

Урон случайный: 50–160% силы. Шанс критического удара — 15%, множитель — 1.8.
Замах занимает 65% интервала с разбросом ±20%, восстановление — 35%.
За убийство восстанавливается 25% максимального HP (округление вверх),
не превышая максимум. При росте уровня добавляется прирост максимального HP,
а уже потерянное здоровье сохраняется. В оверлее показываются криты и лечение.
Тело исчезает через 3 секунды, повторный вход после смерти — через 30 секунд.
После 15 минут без боя персонаж уходит с экрана.

Опыт и выбранные образы сохраняются в `userData/settings/arena.json` каждые
5 секунд и при штатном выходе. Активные бойцы после перезапуска не восстанавливаются.
Идентификация: площадка + ID пользователя (когда чат передал его), иначе ник.
При смене ника на платформах без ID прогресс автоматически не переносится.

В настройках: пауза, 2–50 бойцов (по умолчанию 24), размер 70–200 px
(по умолчанию 130), очистка экрана без удаления опыта.
Расчёт боя выполняется на сервере TChat. Превью/несколько OBS-источников
не ускоряют бой. Вся поверхность оверлея прозрачна, ники выводятся как текст.

Проверки: `node --test scripts/arena.test.js`, `node scripts/test-arena-browser.js`,
`npm.cmd run server:check`, `ARENA_SMOKE=1 node scripts/test-arena-integration.js`.
Тесты боёв используют изолированные настройки, реальные сообщения зрителей не отправляются.
